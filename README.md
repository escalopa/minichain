# minichain

Учебный блокчейн с нуля: ядро на **Rust**, тулинг на **Go**.

## Архитектура

```
minichain/
├── node/       Rust — ядро: блоки, PoW, мемпул, P2P, JSON-RPC API
├── explorer/   Go   — block explorer: REST API + веб-страница поверх ноды
└── wallet/     Go   — CLI-кошелёк: ключи, подпись транзакций, отправка
```

Нода — единственный источник правды. Go-сервисы общаются с ней только
через HTTP API, как настоящий explorer с настоящей нодой.

## Роадмап

- [x] **Фаза 1 — цепочка блоков** (Rust): блок, SHA-256, Proof-of-Work,
      валидация цепочки, тесты
- [ ] **Фаза 2 — транзакции** (Rust): ed25519-ключи, подпись/проверка
      транзакций, мемпул, coinbase-награда, балансы (UTXO или account-модель)
- [ ] **Фаза 3 — HTTP API** (Rust, axum): `GET /blocks`, `GET /balance/:addr`,
      `POST /tx`, `POST /mine`
- [ ] **Фаза 4 — explorer** (Go): опрос ноды, кэш в памяти/SQLite,
      REST + простая HTML-страница со списком блоков и поиском
- [ ] **Фаза 5 — кошелёк** (Go, cobra): `wallet keygen | balance | send`
- [ ] **Фаза 6 — сеть** (Rust, libp2p): несколько нод, gossip блоков,
      разрешение форков по правилу самой длинной цепи

## Запуск

```sh
cd node && cargo run       # смайнить демо-цепочку
cd node && cargo test      # тесты ядра
```
